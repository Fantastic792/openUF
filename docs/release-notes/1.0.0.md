## openUF 1.0.0

The first full release of this openUF fork. openUF lets a router running OpenWrt act as an
access point managed by Ubiquiti's UniFi Network controller: the controller adopts it, sends it
your WiFi networks, and shows its clients, just as it would for one of Ubiquiti's own access
points.

### What you get

- **Easy setup.** One command on the router installs openUF, turns the router into an access
  point, and gets it ready for the controller to adopt.
- **Your WiFi from the controller.** WPA2, WPA3 and Enhanced Open networks, a separate
  password per device (each on its own network if you want), guest WiFi with the
  controller's login page, speed limits, WiFi schedules, and steering phones to the faster
  5 GHz band.
- **Smooth moving between access points.** Phones that support it move between openUF
  access points with almost no break in the connection.
- **Wireless backup link (mesh).** If an access point loses its cable, it connects to
  another access point over WiFi by itself, and goes back to the cable when it returns. This
  now works over more than one hop.
- **Keeps clients off a dead network.** If an access point loses its way to the internet,
  it switches its WiFi off so phones move to an access point that still works, and switches
  it back on when the connection returns.

### Fixed since the beta releases

- The access point now really shows its name in the WiFi network list when you ask the
  controller to.
- WPA3 and Enhanced Open networks are no longer downgraded right after the router is
  adopted.
- A device's own network (with per-device passwords) no longer gets lost when that WiFi
  network is turned off and on again.
- After a reboot with a wrong clock, the clock is now corrected quickly, so fast roaming
  keeps working.
- After an upgrade, the new version starts straight away instead of the old one staying in
  memory.

### Good to know

- This release has been tested every day on two JioRouter AX6000 routers and in an
  automated virtual lab. Other routers should work but have not been tested by this project.
  The README lists exactly what was and was not tested.
- Known issues are listed in the README. 1.0.1 fixes two of them: please upgrade.
