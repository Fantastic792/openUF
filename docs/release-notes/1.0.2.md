## openUF 1.0.2

Fixes the install command on a fresh OpenWrt router, and adds three small things the UniFi
controller already asks for. Your settings are kept.

### What got fixed

- **The install command could stop at "download failed".** On a fresh OpenWrt 25.12
  router, the built-in download tool gets no answer from github.com, where openUF's files
  are kept, even though other GitHub addresses work fine. The setup and update scripts now
  fetch the same files through GitHub's other address when that happens. Every file is
  still checked against the signed checksum list, so nothing about safety changes.
- **The install command could stop at "not signed by the openUF release key".** Checking
  that signature needs a tool (`openssl`) that a fresh OpenWrt 25.12 router does not have.
  The installer now adds it from OpenWrt's own package list first.
- **The install command could stop at "required and could not be installed: iw".** Many
  OpenWrt images come with the bigger `iw-full` instead of `iw`. The installer now accepts it.
- **The dependency check was broken.** `openuf deps` (and the dependency page in the
  router's web interface) failed with a "syntax error" since 1.0.0, so it could neither
  report nor install missing packages. Fixed, and the build now checks every shipped
  script so this cannot slip through again.
- **A MAC filter with no addresses yet stopped every WiFi change.** Turning on "MAC
  Address Filter" (allow list) before adding any device made the access point reject the
  whole WiFi update, again on every check-in. It now applies it: with an empty allow list
  nobody can join that network, the same as on a UniFi access point.

### What's new

- **Remote logging.** If you set a syslog server in the controller (Settings, System,
  Remote Logging), the access point now sends its log there. Turning it off puts back
  whatever the router had before. UniFi's own encrypted logging is not supported yet.
- **Channel width in the client list.** The controller showed every WiFi client at 20 MHz.
  It now shows each client's real width (20, 40, 80 or 160 MHz).
- **Older Apple devices.** WPA2 networks no longer offer an extra security mode
  (`WPA-PSK-SHA256`) that a real UniFi access point never offers and that some older
  MacBooks refuse to join.

### How to upgrade

On the router, over SSH:

```sh
apk update && apk upgrade        # if you installed from the openUF package feed
openuf-update                    # any other install
```

### For the technically minded

- `setup.sh`/`update.sh`: `fetch_asset` falls back from `browser_download_url` to the API
  asset URL with `Accept: application/octet-stream` (302 to the release CDN). rrb-unifi
  comes from `codeload.github.com`. Seen in the VM lab: uclient-fetch with
  libustream-mbedtls on 25.12.6 completes TCP to github.com but never finishes the fetch.
  `verify_sums_sig` installs `openssl-util` (apk or opkg) when there is no `openssl`.
  The REQUIRED check takes `<name>-full` for `<name>` (`iw-full`). The README install ran
  end to end in the VM lab on stock 25.12.6 (two reboots after); a 1.0.0 -> 1.0.1 upgrade
  through the signed apk feed kept `/etc/openuf/conf.lua`.
- `openuf-deps.sh`: the `PACKAGES` list lost its closing quote in a 2026-10-25 refactor;
  the source still parsed, the comment-stripped copy in the packages did not.
  `tools/dist.sh --verify` now runs `sh -n` on every stripped script.
- `ucihelper`: an empty list value (an allow-type `maclist` with no entries) is deleted,
  not handed to libuci-lua, which throws on `{}` and failed the wifi part of the push (F-5).
- `sysconf`: `syslog.status`, `syslog.remote.{status,ip,port}` to logd
  `log_ip`/`log_port`/`log_proto`; the board's own target is stamped and restored.
  `syslog.remote.encrypt` stays in the unhandled ledger.
- `inform`: `chwidth` (0..3 = 20..160 MHz) on each `sta_table` row.
- `ucihelper`: on psk2 with PMF and on sae-mixed, a raw `wpa_key_mgmt` line with iface.uc's
  list minus `WPA-PSK-SHA256` (VM lab: WPA2 + FT + PMF optional runs `key_mgmt=WPA-PSK
  FT-PSK` per `hostapd_cli get_config`; a client join on that BSS is not yet checked).
- Ideas from [antoniocosta/unifi-openwrt](https://github.com/antoniocosta/unifi-openwrt),
  written fresh in Lua.
