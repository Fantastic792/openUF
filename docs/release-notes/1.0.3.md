## openUF 1.0.3

Fixes signing in after a fresh 1.0.2 install, and adds a button to get to LuCI. **If you
installed 1.0.2 with the install command, please upgrade.** Your settings are kept.

### What got fixed

- **The right password was refused as "not correct".** The 1.0.2 installer updated the
  router's web server but not the part of it that checks the password. The two did not
  work together: the web server crashed on every sign-in, so neither LuCI nor openUF's page
  let you in, and openUF's page called that a wrong password. SSH was not affected. The
  installer now updates all the parts together, and openUF's page says when the device
  could not check the password instead of blaming the password.

  A router that already has the problem: over SSH run
  `apk upgrade uhttpd uhttpd-mod-ubus uhttpd-mod-ucode` and reboot. Upgrading openUF alone
  does not touch the web server.

### What's new

- **An "Open LuCI" button.** openUF's page replaces LuCI at the router's address, and the
  way back to LuCI was hidden (a key sequence, or seven taps on the device picture). After
  you sign in under Local Settings there is now an *Open LuCI* button at the top.

### How to upgrade

On the router, over SSH:

```sh
apk update && apk upgrade        # if you installed from the openUF package feed
openuf-update                    # any other install
```

### For the technically minded

- `setup.sh`: `upgrade_uhttpd` runs `apk upgrade uhttpd` (or opkg) with each installed
  `uhttpd-mod-ubus` and `uhttpd-mod-ucode`. 1.0.2 left `uhttpd-mod-ubus` out: uhttpd
  2026.11.05 with mod-ubus 2026.08.24 segfaults in libubox on every `/ubus` call, so
  `session.login` never answers.
- `80_openuf-portal`: the fix hint names all three packages.
- `portal.js`: "not correct" only for ubus code 6 (permission denied); any other failure
  shows the error and the upgrade command. The *Open LuCI* button reuses the unlock prompt.
- Proven in the VM lab on stock 25.12.6 (login on the device page and the LuCI form after
  the three-package upgrade, the button reaching LuCI's login). Not verified on hardware.
- Full list of commits: compare `v1.0.2...v1.0.3` on GitHub.
